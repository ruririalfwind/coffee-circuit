# 咖啡赛事台 Coffee Circuit

为咖啡从业者与爱好者整理的赛事信息站：杯测、冲煮、拉花、咖啡师、烘焙赛事聚合，含主办方、含金量、历史规模与选手介绍，卡片可直接跳转官方报名页。

## 工作原理（全自动）

```
每天 10:15（北京时间）
  └─ GitHub Actions 定时触发 daily.yml
      ├─ scripts/update.py 抓取 HOTELEX 官方咖啡赛事栏目
      ├─ 新赛事自动合并进 data.json（id 顺延、标记 NEW）
      └─ 有变更则自动 commit + push
          └─ 触发 pages.yml → 自动部署 GitHub Pages
              └─ 线上网站即时更新，全程无人值守
```

- 数据文件：`data.json`（唯一数据源，前端 `index.html` 运行时加载；本地打开时自动回退到内置快照）
- 更新脚本：`scripts/update.py`（标准库实现，无需第三方依赖）
- 自动部署：`.github/workflows/pages.yml`（GitHub Pages）

## 手动维护赛事

`data.json` 的 `events` 数组是唯一数据源，直接编辑并 push 即可（部署会自动触发）。

字段说明：

| 字段 | 含义 |
|---|---|
| id | 数字，顺延递增 |
| name | 赛事名称 |
| cat | tasting / sensory / barista / latte / brew / roast |
| lv | 级别（国际·中国区 / 城市赛 / 民间等） |
| date / place / fee | 时间 / 地点 / 费用 |
| status | open（可报）/ soon（即将或待确认）/ done（已完赛） |
| statusTxt | 状态徽标文字 |
| region | 江浙沪 / 西南 / 华南 / 华中 / 北方 / 全国 |
| desc / route / ch | 描述 / 晋级路径 / 报名渠道 |
| link / linkTxt | 报名或官方发布链接（卡片按钮） |
| src | 信息来源 |
| isNew | true 时显示 NEW 徽标 |

## 手动触发更新

仓库 Actions 页面 → Daily Update → Run workflow（无需等定时）。

## 数据口径

- 自动抓取仅收录标题含当年年份（2026/2027）的咖啡类赛事，来源为 HOTELEX 官网咖啡赛事栏目；
- 抓取失败时保留现有数据不中断；
- 报名信息以主办方官方发布为准。

## 链接配置与核验规则（重要）

卡片上的「跳转报名」链接遵循以下规则，确保**信息源与跳转链接一一对应**：

1. **来源优先级（官方渠道优先，含报名链接最优先）**：
   - 最高级：主办方官方渠道 **且包含报名/预约入口**——官方网站报名页、官方微信公众号文章、官方抖音/微博/小红书发布（例：云南杯测赛官方公众号"报名通道开启"、PCA 官网"赛区报名"页、昆山展官方抖音免费领票、CCC/CCT 官方抖音招募视频）；
   - 次高级：主办方官方渠道但暂未开放报名入口（例：HOTELEX 官方赛事栏目页，报名开放前保持官方入口）；
   - 兜底级：主流媒体官方账号对官方细则的转载（网易新闻、新浪财经、新民晚报等），仅在无官方一手源时使用并如实标注；
   - 社区论坛文章不视为报名入口，仅作信息线索。
   - 微信文章链接（mp.weixin.qq.com）无法自动抓取正文，以其在政府/主办方官方页面中被引用、且标题与赛事对应为准；手机端可直接打开。
2. **对应性核验**：每条链接的页面标题或正文，必须包含该赛事的名称、赛区、年份等关键字段，与卡片内容一致才算通过。
3. **抖音链接规范**：仅使用该赛事官方发布的视频（文案含赛区名 + 时间）；链接统一用 `https://www.douyin.com/video/{视频ID}` 格式——手机端打开会自动唤起抖音 App，便于直接报名。
4. **自动抓取天然对应**：`scripts/update.py` 从 HOTELEX 官方栏目页按「标题 + 详情链接」成对提取，两者出自同一 DOM 元素，不存在错配可能；且只收当年年份（2026/2027）。
5. **如实标注**：`linkTxt` 按链接实际性质填写（官方发布 / 官方详情 / 媒体报道 / 信息汇总），不把媒体报道冒充报名入口。
6. **宁缺毋滥**：查不到官方来源或无法核验内容的赛事，不下发或下架（例：曾有一条"苏州赛区"因查无官方发布依据、链接实为太原赛区视频，已移除）。
7. **变更后复查**：人工改动链接后，运行 `python scripts/verify_links.py` 批量抓取所有链接的标题并人工比对。

核验脚本：`scripts/verify_links.py`（批量抓取 data.json 中每条 link 的落地页标题，输出与卡片期望的对照）。
